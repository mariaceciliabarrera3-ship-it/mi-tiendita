# Lectura de remitos y facturas para compras

En **Compras → Registrar compra**, primero necesitás un proveedor y productos en tu catálogo. La carga manual sigue disponible. Elegí foto JPG/PNG o PDF de hasta 8 MB (imagen hasta 20 megapíxeles; PDF máximo 3 páginas) y tocá **Leer documento**. Se extrae texto PDF con Poppler o se ejecuta Tesseract local para fotos/PDF escaneado; no se usa API paga ni se conserva deliberadamente el documento: archivos temporales se eliminan al terminar. Si un proceso o servidor cae bruscamente, puede quedar un archivo temporal; proteger y limpiar el directorio temporal. La petición, los archivos temporales y memoria del servidor pueden contener datos privados: usá HTTPS, controlá acceso, límites del proxy y permisos. No se registra un comprobante fiscal ni se realiza ninguna compra al analizar.

La pantalla de revisión muestra renglones candidatos y el texto completo. Compará con el original **cada línea y su unidad**; corregí cantidad y costo unitario y elegí manualmente su producto del catálogo. Marcá solo los renglones verificados y agregalos a la compra. Volvés al carrito existente, donde podés quitar/agregar artículos, elegir proveedor y cargar pagos; solo **Registrar compra** intenta guardar, actualizar stock y deuda. Podés cancelar o descartar. Si no se reconoció algo, agregalo manualmente. Ninguna vinculación es automática.

## Confiabilidad y límites reales
Es una ayuda, no una lectura garantizada ni un modelo de facturas universal. Solo propone algunos formatos de columnas: descripción, cantidad, precio unitario, opcional total; también cantidad–descripción–precio. Las columnas pueden confundirse y se pueden perder líneas sin aviso. Las descripciones editadas son para revisión: el artículo final es el del catálogo elegido, no se crea uno nuevo. No se interpretan automáticamente bultos, fracciones, IVA, moneda, descuentos o totales; no presupone que precios netos/brutos sean equivalentes al costo que necesita el negocio. Separadores de miles con un solo punto o coma son ambiguos y pueden interpretarse mal. No se comprueba que cantidad × precio coincida con total impreso; hacelo manualmente. Revisá y ajustá toda la compra, impuestos, descuentos y pagos comparando con el documento. No existe una tasa de precisión medida; fotos borrosas, torcidas, oscuras, manuscritas, facturas con formatos complejos y PDF mixtos (texto más imagen) son especialmente poco confiables. Un PDF mixto puede usar solo el texto incrustado y omitir páginas con imagen. Ante dudas, usar carga manual. No probar con documentación sensible sin autorización del comercio.

## Instalación y pruebas
En Debian/Ubuntu: `sudo apt install tesseract-ocr tesseract-ocr-spa tesseract-ocr-eng poppler-utils` y `pip install -r requirements.txt`. Verificá `tesseract --list-langs` (`spa`, `eng`), `pdfinfo -v`, `pdftotext -v` y `pdftoppm -v`. Dockerfile y `render.yaml` usan imagen Docker que los instala; migrar un servicio Python existente a Docker requiere ajuste/redeploy y puede cambiar tiempos/costos. No se verificó build en Render ni Docker en esta entrega (ver `AUDITORIA_Y_PENDIENTES.md`, sección 3). Si faltan binarios el servicio responde error claro; la carga manual sigue funcionando. Se limita la extracción simultánea por instancia (`OCR_MAX_CONCURRENT`, 1 por defecto), el tamaño de página de los PDF y los tiempos por subproceso; hay límites de memoria/CPU y formatos maliciosos pueden agotar recursos. Aislar este procesamiento, actualizar dependencias, limitar tráfico/tamaño desde el proxy y proteger temporal antes de operar a escala.

Se probaron imagen PNG generada sintéticamente con dos filas, PDF escaneado derivado de esa imagen y PDF digital sintético, lectura real Tesseract/Poppler; los tres se ejecutaron en SQLite y PostgreSQL. En PDF digital se simularon elección y confirmación vía API y se comprobaron los dos stocks y total de compra. También se probó que extracción no modifica stock y se rechazan archivo inválido y mayor a 8 MB. No se probó la interfaz en navegador ni fotos reales de comercio ni se midió precisión en un conjunto representativo.
