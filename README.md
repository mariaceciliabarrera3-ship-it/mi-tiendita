# Mi Tiendita 🏪

Asistente de Inteligencia Artificial sobre WhatsApp Business para comerciantes de barrio y PyMEs.

## 🚀 Descripción
Mi Tiendita permite a pequeños comerciantes gestionar su catálogo, registrar ventas manuales, responder consultas de clientes, gestionar stock y obtener reportes con margen de ganancia mediante mensajes de voz y texto en WhatsApp.

## 🛠️ Tecnologías y Servicios ($0/mes)
- **Framework:** FastAPI / Uvicorn
- **Hosting:** Render Free Tier
- **IA Generativa:** Groq API (Llama 3.3 70B & Whisper v3 Turbo)
- **Base de Datos:** Neon Postgres Serverless
- **Canal:** WhatsApp Business API (Meta)
